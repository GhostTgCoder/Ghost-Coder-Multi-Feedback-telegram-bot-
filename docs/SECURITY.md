# Безопасность

## Не публикуйте

- Telegram bot tokens и содержимое `.env`;
- рабочие `bots_config.json`, файлы состояния и базы обращений;
- реальные Telegram ID, пользовательские сообщения, экспорт переписки и логи с персональными данными;
- приватные ключи, пароли и резервные копии без шифрования.

## Минимальные меры

- Отдельный системный пользователь и ограниченные права на файлы.
- Закрытая группа операторов; выдавайте боту только необходимые права.
- Регулярные обновления Python и зависимостей.
- Шифрование резервных копий и контроль доступа.
- Ротация токенов при подозрении на утечку.
- Проверка доступа к административным командам на тестовой установке.

## Сообщить об уязвимости

Не публикуйте токены, эксплойты или персональные данные в открытом issue. Свяжитесь с продавцом через страницу продукта на Kwork и приложите минимальное воспроизведение без секретов.

Этот документ — базовая памятка, а не подтверждение проведения независимого аудита безопасности.
