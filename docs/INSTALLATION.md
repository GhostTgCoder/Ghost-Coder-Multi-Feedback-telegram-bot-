# Требования и установка

> Эта документация описывает типовой процесс. В данном репозитории нет исходников приложения. Для установки рабочего продукта получите комплект файлов через страницу покупки и следуйте инструкции, соответствующей поставленной версии.

## Требования

- Linux VPS/сервер с доступом к командной строке.
- Поддерживаемая версия Python 3 (проверьте требования конкретной поставки).
- Telegram-боты, созданные через `@BotFather`.
- Форумная группа поддержки с включёнными темами.
- Права ботов на чтение и отправку сообщений в нужных чатах/каналах.
- PM2 — только если используемый способ запуска основан на PM2.

## Общий порядок

1. Создайте ботов через `@BotFather` и сохраните токены в секретном хранилище.
2. Создайте закрытую форумную группу для операторов и включите темы.
3. Добавьте нужных ботов в группу и выдайте необходимые права.
4. Установите Python и зависимости из `requirements.txt` поставки.
5. Создайте локальную конфигурацию по шаблону, заполните ID администратора, группы и токены.
6. Запустите один экземпляр приложения и проверьте тестовый сценарий: обращение → тема → ответ → доставка пользователю.
7. Настройте автозапуск, логи, резервные копии и мониторинг перезапусков.
8. Перед подключением реальных клиентов проверьте все используемые функции и права.

## Проверка после установки

- Бот отвечает на `/start`.
- Сообщение тестового пользователя создаёт или использует корректную тему.
- Ответ оператора приходит правильному пользователю.
- Вложения обрабатываются согласно настройкам.
- Несколько ботов не пересекают сообщения и настройки.
- После перезапуска состояние сохраняется в ожидаемом объёме.
- Токены и персональные данные не попадают в публичные логи.
