# Возможности продукта

## Поддержка клиентов

1. Пользователь открывает диалог с Telegram-ботом и отправляет обращение.
2. Бот направляет сообщение в форумную группу поддержки и связывает его с темой пользователя.
3. Оператор отвечает в соответствующей теме; бот доставляет ответ пользователю.
4. При доступности функций оператор может просматривать историю, использовать шаблоны и управлять состоянием диалога.

## Несколько ботов

Одна установка может обслуживать несколько Telegram-ботов. Для каждого задаются собственные параметры, тексты приветствия, язык, каналы и группа обращений. Каждый бот требует отдельного токена, а конфигурации не должны содержать токены чужих или демонстрационных ботов.

## Управление обращениями

В зависимости от настроек доступны автоответы, лимиты частоты сообщений, автоматическое закрытие, назначение оператора, категории, теги, приоритеты, напоминания и рабочие часы. Включайте только те функции, которые нужны вашей команде, и проверяйте их на тестовом окружении.

## Каналы и подписки

При соответствующей настройке бот может проверять подписку пользователя на обязательные каналы. Для проверки бот должен иметь возможность получать актуальные сведения о членстве; проверьте настройки приватности и права в канале.

## Модерация и публикации

В проекте присутствуют отдельные компоненты для групповой модерации и публикации сообщений в каналы. Доступные правила и возможности зависят от конфигурации и прав бота.

## Ограничения

Telegram Bot API ограничивает частоту и доступность некоторых операций. Бот не сможет отправлять сообщения пользователю, который не начал диалог или заблокировал его. Не обещайте пользователям SLA, автоматическое восстановление или безошибочную доставку без собственных испытаний.
