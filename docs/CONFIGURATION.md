# Конфигурация

Названия полей могут отличаться между версиями. Используйте только шаблоны, поставленные вместе с вашей сборкой; не копируйте рабочие конфигурации в публичный репозиторий.

## Переменные окружения

В исследованной версии `config.py` загружает `.env` и читает:

| Переменная | Назначение |
|---|---|
| `ADMIN_ID` | Telegram ID главного администратора; по умолчанию код использует `0`, что не следует считать корректной рабочей настройкой. |
| `LOG_GROUP_ID` | ID группы для журналирования, если используется. |
| `ADMIN_BOT_TOKEN` | Токен административного бота. |

Не указывайте реальные значения в Git. Используйте секреты окружения и ограничьте права доступа к конфигурации.

## Параметры каждого бота

В примерной структуре присутствуют настройки токена, языка, канала и ссылки, форумной группы, каналов публикации и подписки, приветствия, кнопок, стиля сообщений и рабочих часов. Конкретные ключи и форматы следует брать из `bots_config.example.json` вашей поставки.

## Рабочие часы

Если функция включена, задайте часовой пояс и временные интервалы для рабочих дней. Проверьте переход через полночь, выходные, часовой пояс сервера и текст автоответа вне графика. Не включайте функцию, пока не проверили формат расписания в вашей версии.

## Настройки диалога

Некоторые параметры — автоответы, интервалы, последовательные сообщения, авто-закрытие, назначение операторов и разрешённые типы вложений — могут иметь зависимости друг от друга. Меняйте их постепенно и тестируйте.

## Безопасная конфигурация

- Не коммитьте `.env`, рабочие JSON-файлы, дампы или логи.
- Не публикуйте реальные токены, Telegram ID клиентов и историю обращений.
- Не используйте токены из примеров: создавайте собственные.
- При утечке токена немедленно отзовите его через `@BotFather` и замените в конфигурации.
